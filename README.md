# school347 — v0.4 (структура для Render)

Эта версия собрана под структуру, которая уже настроена у тебя на
Render: `index.js` и `package.json` лежат в корне, а клиент — в
папке `client` рядом с ними.

```
(корень репозитория)
├── index.js
├── package.json
└── client/
    └── index.html
```

## Как запустить локально

1. Установи [Node.js](https://nodejs.org) версии **22 или новее**
2. Открой терминал прямо в этой папке (там же, где `index.js`)
3. Выполни:
   ```
   node index.js
   ```
4. Открой в браузере: `http://localhost:8080`

## Что исправлено в этой версии

1. **wss:// вместо ws://** — на HTTPS-страницах (как на Render)
   браузер требует защищённое WebSocket-соединение. Раньше клиент
   всегда пытался подключиться по `ws://`, что браузер блокировал
   на HTTPS. Теперь клиент сам определяет нужный протокол.

2. **Путь к клиенту** — сервер теперь ищет `client/index.html`
   рядом с собой (а не на уровень выше), что соответствует твоей
   текущей структуре репозитория на GitHub.

## Как обновить на GitHub

Если у тебя уже есть репозиторий с похожей структурой — просто
загрузи (Add file → Upload files) эти три элемента в корень,
заменив старые:
- `index.js`
- `package.json`
- папку `client` (с файлом `index.html` внутри)

Render подхватит изменения автоматически после коммита.
