## Чтобы данные больше не пропадали (Turso)

На бесплатном Render диск стирается при каждом засыпании/перезапуске, поэтому
файл базы данных там жить не может. Данные нужно хранить во внешней базе — Turso.

1. Зарегистрируйтесь на https://turso.tech (можно через GitHub) и создайте базу `school347`.
2. На странице базы скопируйте её адрес (вида `libsql://school347-....turso.io`)
   и создайте токен доступа (кнопка вроде «Generate Token», права на чтение и запись).
3. В Render откройте сервис → **Environment** → добавьте две переменные:
   - `TURSO_DATABASE_URL` — адрес базы
   - `TURSO_AUTH_TOKEN` — токен
4. Сохраните — Render перезапустит сервис. В **Logs** должна появиться строка
   `📦 База данных: Turso (облачная база, данные постоянные)`.

Токен — это пароль к вашей базе. Храните его только в переменных Render и
никогда не загружайте на GitHub.

Если переменных нет, сервер работает с локальным файлом `school347.db`
(удобно для проверки на своём компьютере: `node index.js`, затем http://localhost:8080).
