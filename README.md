# school347 — v0.4

Мессенджер с регистрацией по Gmail, паролем, чатом класса и дизайном,
приближенным к Telegram: тёмная/светлая тема, аватарки, полноценные
настройки профиля.

## Как запустить

1. Установи [Node.js](https://nodejs.org) версии **22 или новее**
   (проверить: `node -v`)
2. Открой терминал внутри папки `server`
3. Выполни:
   ```
   node index.js
   ```
4. Открой в браузере: `http://localhost:8080`

Если у тебя уже есть файл `school347.db` от предыдущей версии — не
удаляй его, все твои пользователи сохранятся. Сервер сам добавит
недостающие поля в базу при первом запуске (аватарка, отображаемое
имя, тема, уведомления).

## Что нового в этой версии

### Дизайн — ближе к Telegram
- Более точная цветовая палитра (тёмная и светлая тема)
- Аккуратные тени, скругления, анимации при переключении экранов
- Узкая колонка слева теперь показывает твою аватарку сверху — как
  переключатель аккаунтов в Telegram Desktop
- Лёгкий фоновый паттерн в окне переписки
- Более плотная, «настоящая» вёрстка списков чатов — время последнего
  сообщения, аватарки собеседников везде (в списке чатов, в поиске, в
  самой переписке)

### Полноценные настройки профиля
В разделе **👤 Профиль** теперь можно менять:
- **Аватарку** — клик по фото открывает выбор файла с компьютера;
  картинка автоматически сжимается прямо в браузере до разумного
  размера перед отправкой на сервер (чтобы не раздувать базу данных)
- **Отображаемое имя** — то, что видят другие люди в чатах
- **Username** — можно сменить в любой момент, с той же проверкой
  уникальности, что и при регистрации
- **Класс** — если перевели в другой класс
- **Пароль** — с проверкой текущего пароля перед сменой

В разделе **⚙️ Настройки** реально работают:
- **Тёмная / светлая тема** — применяется сразу и запоминается
- **Уведомления вкл/выкл** — переключатель сохраняется на сервере
  (сама отправка уведомлений операционной системой — это следующий
  шаг, пока сохраняется только сам факт предпочтения)

## ⚠️ Реальная отправка кода на почту — ты уже в процессе подключения

Мы разбираем это отдельно: домен на eu.org подан на рассмотрение,
дальше — Cloudflare (DNS) → Resend (отправка писем) → API-ключ. Как
только у тебя будет готовый API-ключ, пришли его мне (или просто
скажи, что домен одобрили) — я сразу подключу реальную отправку в
код сервера, в функцию `handleRequestCode`, помеченную `⚠️`.

До этого момента код подтверждения показывается прямо в интерфейсе
регистрации (зелёная подсказка) и в консоли сервера — только для
тестирования.

## Структура базы данных

- `users` — email, username, **display_name**, **avatar_data**, класс,
  хеш пароля, **theme**, **notifications_enabled**
- `sessions` — токены долгих сессий
- `direct_messages` — личные переписки
- `class_chat_members` / `class_chat_messages` — чаты классов

Новые поля (жирным) добавлены автоматически при первом запуске этой
версии сервера — старые данные не теряются.
